# Saldo

Este repositorio público contiene la página de presentación de Saldo y se
utiliza para publicar sus releases e instaladores para Windows.

## Sobre Saldo

Saldo es una aplicación de gestión financiera personal. Sirve para organizar
el presupuesto, registrar gastos e ingresos, anticipar pagos recurrentes y
definir metas de ahorro de acuerdo con el dinero realmente disponible.

Su fin es ayudar a tomar decisiones financieras con más claridad: saber cuánto
queda del ciclo actual, prever compromisos próximos y planificar el ahorro sin
comprometer el presupuesto cotidiano.

El código fuente y el desarrollo actual se mantienen en el repositorio privado
`CriissH/s-gestion-app`.

Consulta la pestaña **Releases** para descargar las versiones publicadas.
