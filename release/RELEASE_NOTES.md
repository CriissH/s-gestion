# Saldo 1.0.7

## Instaladores para Windows

- `Saldo-1.0.7-windows-x64-setup.exe`: instalador NSIS recomendado.
- `Saldo-1.0.7-windows-x64.msi`: paquete MSI para despliegues administrados.

## Cambios principales

- Proyección mensual después de gastos recurrentes.
- Estados de recurrentes: aprobado, rechazado y pendiente.
- Ingresos recurrentes gestionables desde Ajustar ingreso.
- Avisos de recurrentes pendientes debajo del presupuesto.
- Barra inferior fija para recurrentes del día, sin cubrir la barra lateral.
- Reporte “Qué conviene abonar” según vencimientos, presupuesto y otros ingresos.
- Metas de ahorro limitadas prudentemente al 30% del presupuesto restante.

## Integridad

Usa `SHA256SUMS.txt` para verificar los archivos descargados antes de instalarlos.
